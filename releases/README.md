# iqoo越狱工具 - 版本管理规范

## 目录结构
根目录只保留当前最新安装包, 历史版本全部归档到 releases\
每次升级: 旧包自动进 releases\vX.Y\, 绝不覆盖

## 升级流程(一条命令)
python bump_version.py 1.2
自动: versionCode+1 → 重打包 → 16K对齐 → 签名 → 旧包归档 → 新包出根目录

## 防覆盖保护(脚本强制)
- 版本号相同拒绝执行
- 根目录已有同名新包→拒绝输出
- 归档目录已有同名: hash相同删根目录冗余; 不同则保留双份(.prev)
- 任何情况下旧安装包不会丢失

## 回滚方法
新版出问题: 从 releases\vX.Y\ 复制旧包安装即可(同签名可覆盖降级)
